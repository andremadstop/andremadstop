Photographer in Potsdam since 2012: architecture, monuments, 360°, aerial and measurement images. Founder of Stiebitz Souverain Systems UG, a small IT company for small teams: cloud, backup and monitoring that the team owns, security checks, 3D surveys from laser scans and photos, training in IT security. Linux and my own servers have run alongside both for years; the repositories here grew out of that.

## How the code is made

I am not a programmer. The code here is written mostly with Claude (Anthropic); I set the task, review and test the result in my own work, and run it. I say so openly. No data belonging to others goes in, and I claim no rights I am not sure I hold: core projects under copyleft with the note "applies as far as rights exist", small tools under a permissive licence. I charge for running these systems and taking responsibility for them. Everything here also has a full copy on my own infrastructure.

Each of these tools stands on other people's open-source work. The repositories say so by name, with purpose and licence, in a `DANK.md` or `ACKNOWLEDGEMENTS.md`, the way a thesis lists its sources.
